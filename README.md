# Dobby

แอป Desktop สำหรับควบคุมตัวละคร AI และปฏิสัมพันธ์ TikTok LIVE ผ่าน Euler Stream โดยใช้ TikTok LIVE Studio ออกอากาศ และเชื่อม Codex ผ่าน MCP/Plugin

**ติดตั้งและใช้งานจริง:** ดู [INSTALL.md](INSTALL.md) — ตั้งแต่สิ่งที่ต้องมี การ build การต่อ TikTok LIVE Studio การซ้อม จนถึงวันไลฟ์จริง

เวอร์ชัน 0.8.0 เน้นความลื่นและการดึงผู้ชมให้อยู่ต่อ:

- **ลื่นขึ้น ใช้ทรัพยากรน้อยลง:** เสียงปากแยกช่องจาก state, รวมรอบส่งข้อมูลไม่เกิน 10 ครั้ง/วินาที, Live2D ตัวเดียวใช้ซ้ำข้ามหน้า (preview จำกัด 30 fps และหยุดเมื่อไม่ได้แสดง), เก็บโปรเซส Codex ไว้ใช้ซ้ำ, cache ไฟล์โมเดล
- **หน้า Debug / ทดสอบ:** ค่า FPS, ความถี่ส่งข้อมูล, CPU/RAM ต่อโปรเซส, เวลาตอบผู้ชม, บันทึกสถานะ, ส่งเหตุการณ์ทดสอบ และโหมดซ้อม Auto Host โดยไม่ต้องเชื่อม Euler
- **Overlay บนจอไลฟ์:** ซับไตเติลคำพูดและการ์ด "กำลังตอบ @ชื่อ" พร้อมตัวกรองคำ (ค่าเริ่มต้นปิด)
- **สีหน้าตามอารมณ์คำตอบ:** 9 อารมณ์ จับคู่กับสีหน้า/ท่าทางของแต่ละโมเดล
- **ทักคนเข้าห้องแบบรวมกลุ่ม:** "ยินดีต้อนรับ A, B และอีก 3 คน" ตอนว่าง ไม่ทักซ้ำ
- **จำขาประจำ:** จำผู้ชมข้ามไลฟ์ในเครื่อง ทักคนที่กลับมา และขึ้นป้ายบนการ์ด
- **ของขวัญแบ่งระดับ:** เล็ก/กลาง/ใหญ่ตามมูลค่า ท่าทางต่างกัน ของใหญ่ได้ตอบก่อนพร้อมการ์ดสีทอง

เวอร์ชัน 0.7.1 เอากล่องแสดงชื่อ/ข้อความผู้ชม คำตอบล่าสุด และบรรทัดคำอธิบายท้ายแผง Auto Host ออก ทั้งหน้าห้องควบคุมและหน้าเสียงพูด

เวอร์ชัน 0.7.0 ปรับการดูแลไลฟ์:

- แนะนำตัวด้วยชื่อคาแรกเตอร์และคำว่า **AI VTuber** เมื่อถามชื่อหรือว่าเป็นอะไร และตอบตามจริงเมื่อถามเจาะจงถึงเทคโนโลยี
- แก้ปากโมเดล Mao ที่บันทึกพารามิเตอร์ผิดเป็น `P`: ตรวจพารามิเตอร์ที่มีจริงและใช้ LipSync จากโมเดล เช่น `ParamA` แทน พร้อมปรับช่วงและความลื่นตามเสียงจริง
- จำบทสนทนาและการคุยระหว่างผู้ชมล่าสุดสูงสุด 300 ข้อความในเครื่อง ข้ามการเปิดแอป ส่งบริบทล่าสุดและประวัติผู้ชมที่กลับมาให้ทั้งโมเดลเสียงและโมเดลข้อความ ล้างได้หลังหยุด Auto Host
- Auto Host เริ่มชวนคุยเมื่อว่างครบ 15 วินาทีหลังเริ่มหรือพูดจบ ระยะเตรียมเสียงขึ้นกับบริการเสียง ไม่พูดซ้อน และให้คิวผู้ชมมาก่อนการเริ่มช่วงว่าง
- เลือก 3 โหมดที่แผง Auto Host: **สนทนากับผู้ชม**, **เล่าเรื่องและคุย** (ใส่แนวเรื่องหรือให้คิดเอง/รับไอเดียผู้ชม), **ขายของ** (กรอกข้อมูลสินค้าที่ให้พูด ไม่สร้างราคา/โปรโมชันขึ้นเอง)
- เอาป้ายชื่อคาแรกเตอร์และกล่องข้อความขอบคุณออกจากพรีวิวและภาพออกอากาศ

ความทรงจำเป็นประวัติแบบมีขอบเขต ไม่ใช่การจำทุกข้อความถาวร ไฟล์ `conversation-memory.json` อยู่ใน userData ของ Dobby และไม่ส่งให้หน้าออกอากาศ การเปิดแอปไม่เริ่ม Auto Host เอง

เวอร์ชัน 0.6.0 เพิ่มโลโก้เอลฟ์ AI และหน้า **โมเดล AI** สำหรับเลือกวิธีคิดคำตอบของ Auto Host รุ่นนี้อยู่ที่ `release-v0.6.0/mac-arm64/Dobby.app`

- **Codex Voice** รับคอมเมนต์หนึ่งครั้งต่อคำตอบ แล้วสร้างคำตอบพร้อมเสียงในเซสชันเดียว เป็นค่าเริ่มต้นเมื่อยังไม่ได้เลือกโมเดลอื่น
- **โมเดลข้อความ** โหลดรายชื่อจาก Codex ที่ล็อกอินอยู่ แล้วเลือกโมเดลเพื่อสร้างข้อความก่อนส่งให้เสียงตัวละครอ่าน

เลือก **ไทย** ในหน้าคาแรกเตอร์และเลือกเสียงในหน้าเสียงพูด ทั้งสองแบบใช้ Codex ที่ล็อกอินด้วย ChatGPT โดยไม่ต้องกรอก OpenAI API key หยุด Auto Host ก่อนเปลี่ยนโมเดล

เวอร์ชัน 0.5.0 เพิ่ม Auto Host ตอบผู้ชมด้วย Codex ผ่าน ChatGPT login โดยไม่ใช้ API key ทดสอบคอมเมนต์จำลองผ่านการสร้างคำตอบและเสียง Codex จริงจนจบแล้ว ส่วนการตอบบนไลฟ์จริงและการใช้งานต่อเนื่องยังต้องทดสอบ

## เปิดแอป

แอป Mac ที่แพ็กแล้วอยู่ที่ `release/mac-arm64/Dobby.app` หากแพ็กบน Mac Apple Silicon หรือโฟลเดอร์สถาปัตยกรรมที่ Electron Builder สร้างขึ้น

รุ่น 0.5.0 รอบนี้แพ็กแยกไว้ที่ `release-next/mac-arm64/Dobby.app` เพื่อไม่เขียนทับแอปที่กำลังไลฟ์อยู่ เมื่อพร้อมเปลี่ยนรุ่น ให้ปิด Dobby เดิมแล้วเปิดแอปใหม่นี้ เชื่อม Euler อีกครั้งและตรวจ source ภาพ/เสียงใน LIVE Studio

สำหรับพัฒนา ต้องมี Node.js 22.12 ขึ้นไป:

```sh
npm install
npm run build
npm start
```

โหมดพัฒนาหน้าจอ:

```sh
npm run dev
```

## สิ่งที่ทำได้แล้ว

- ห้องควบคุมภาษาไทย พร้อม preview ตัวละคร SVG ตัวอย่าง ท่าทาง และเหตุการณ์จำลอง
- คิวคำตอบที่จำกัดจำนวน/อายุ กันเหตุการณ์ซ้ำ และนับของขวัญคอมโบตามจำนวนที่เพิ่ม
- ตั้งบุคลิกและกติกา Action เก็บการตั้งค่าในเครื่อง
- เชื่อม Euler WebSocket ด้วย API key และชื่อช่อง รองรับข้อมูล JSON schema v3
- คลังโมเดล Live2D: นำเข้า .model3.json หรือโฟลเดอร์ สลับโมเดล ปรับขนาด/ตำแหน่ง/กลับด้าน และเล่น motions/expressions
- จับคู่ Action ผู้ชมกับท่าทางหรือสีหน้าที่แต่ละโมเดลมี เก็บการตั้งค่าแยกต่อโมเดล
- เสียงพูดผ่าน Codex CLI ที่ล็อกอินด้วย ChatGPT เลือกเสียงแบบการ์ด ฟังตัวอย่างและพูดข้อความพร้อมขยับปาก โดยไม่ใช้ API key
- Auto Host รับคอมเมนต์/ของขวัญ/ติดตามที่เข้าคิว ตอบในบุคลิกและพูดทีละข้อความ พร้อมปุ่มเริ่ม/หยุด
- รับเสียงจากอุปกรณ์ audio input ที่ผู้ใช้เลือก เพื่อขยับปาก
- ฉากไลฟ์พร้อมพื้นโปร่งใส สีพื้น ไล่สี หรือรูปภาพ รองรับ 9:16, 16:9, 1:1 และขนาดกำหนดเอง
- preview ใช้กรอบอัตราส่วนเดียวกับ output สำหรับเพิ่มเป็น Link source ใน TikTok LIVE Studio
- MCP tools สำหรับสถานะ บุคลิก ท่าทาง บริบทผู้ชม และจอง/จบงานตอบ

## เริ่มทดสอบ

1. เปิดห้องควบคุม แล้วกดคอมเมนต์ ของขวัญ หรือไลก์ในส่วน “ทดลองปฏิสัมพันธ์” เหตุการณ์เหล่านี้อยู่ใน Dobby เท่านั้น ไม่ส่งเข้า TikTok
2. กดท่าทางเพื่อดู preview ตัวละคร และเปิดหน้าต่าง output เพื่อดูภาพสำหรับออกอากาศ
3. เปิดหน้าการเชื่อมต่อ ตั้งค่าบริการที่ต้องการใช้ตามขั้นตอนด้านล่าง

## Codex

ทางที่ตรงที่สุดคือเปิด **การเชื่อมต่อ → Codex → คัดลอกการตั้งค่า MCP** แล้วเพิ่มในไฟล์ตั้งค่า Codex จากนั้นเปิดแชตใหม่ แอปสร้างค่าพาธให้ตรงกับแอปที่กำลังเปิดอยู่ ให้ Dobby เปิดค้างไว้ระหว่างใช้งาน

เครื่องมือที่มี:

| Tool | หน้าที่ |
|---|---|
| `get_status` | อ่านสถานะการเชื่อมต่อ |
| `get_character` | โหลดบุคลิกที่ตั้งไว้ |
| `perform_action` | เล่น neutral / wave / heart / happy / surprised |
| `get_live_context` | อ่านเหตุการณ์ล่าสุดและคิวคำถาม |
| `claim_reply` | จองคำตอบหนึ่งงาน |
| `finish_reply` | จบหรือข้ามงานที่จอง |
| `list_models` | อ่านโมเดลและแอนิเมชันที่นำเข้าแล้ว |
| `select_model` | สลับโมเดล |
| `play_model_animation` | เล่น motion หรือ expression ของโมเดล |
| `set_model_transform` | ปรับขนาด ตำแหน่ง และกลับด้าน |
| `get_scene` | อ่านขนาดและพื้นหลังฉาก |
| `set_scene` | เปลี่ยนขนาดและพื้นหลังฉาก |
| `get_voice_status` | อ่านสถานะเสียงและรายชื่อเสียง Codex |
| `speak_text` | ส่งข้อความให้ Dobby พูดหลังเชื่อมเสียงแล้ว |
| `stop_speaking` | หยุดเสียงและตัดเซสชันเสียง |

มีแพ็กเกจ Plugin แบบ portable ที่ `plugin/` พร้อม `plugin.json`, `mcp.json` และ Skill สำหรับขั้นตอนการใช้งาน Launcher อ่านพาธแอปจากไฟล์เชื่อมต่อในเครื่อง ไม่บรรจุ Euler API key ไว้ใน Plugin

Plugin ยังไม่ได้ติดตั้งหรือเปิดใช้ในบัญชี Codex ของผู้ใช้ การติดตั้งผ่าน local marketplace ขึ้นกับรุ่นของ Codex ส่วนการตั้งค่า MCP ที่แอปแสดงใช้สำหรับเชื่อมโดยตรง

**Voice:** เปิดหน้าเสียงพูดใน Dobby และเชื่อมเซสชัน Codex ก่อน จากนั้นใช้ speak_text เพื่อพูดข้อความผ่านเสียงที่เลือก หาก Auto Host เปิดอยู่ ให้แอปจัดการคิวตอบเอง เพื่อไม่ให้เกิดการตอบซ้ำ

## Auto Host — ตอบไลฟ์อัตโนมัติ

1. เชื่อม Euler กับช่องที่กำลัง LIVE ให้สถานะขึ้นเชื่อมต่อแล้ว
2. เลือกเสียงและสไตล์ในหน้าเสียงพูด แล้วกด **เริ่มตอบไลฟ์อัตโนมัติ** จากหน้านั้น หรือใช้ปุ่มเดียวกันในห้องควบคุมเพื่อใช้เสียงที่บันทึกไว้
3. Dobby เชื่อมเสียง Codex แล้วรับงานจากคิวทีละข้อความ สร้างคำตอบสั้นตามบุคลิก รอเสียงจบก่อนเริ่มงานถัดไป แผงแสดงผู้ชม ข้อความ คำตอบ และจำนวนที่ตอบแล้ว
4. กด **หยุดตอบไลฟ์** เพื่อหยุดรับงานและตัดเซสชันเสียง หรือพัก Action เพื่อพักคิวใหม่โดยปล่อยประโยคปัจจุบันจบ

ค่าเริ่มต้นพูดเฉพาะคอมเมนต์ ของขวัญ และติดตามที่กติกาส่งเข้าคิว คนเข้าและไลก์ไม่ทำให้พูดทุกครั้ง คิวจำกัด 20 งาน อายุ 30 วินาที และมีกติกา cooldown จึงไม่ได้ตอบทุกเหตุการณ์เมื่อผู้ชมส่งมาถี่ ไม่มีการพูดเปิดรายการหรือพูดเองระหว่างไม่มีข้อความ

ต้องกดเริ่มเองหลังเปิดแอปทุกครั้ง หาก Euler หรือเสียงหลุด Auto Host หยุดและแสดงเหตุผล ต้องกดเริ่มใหม่เมื่อพร้อม ขณะเปิด Auto Host เซสชันเสียงคงอยู่โดยไม่ใช้ตัวตัดเมื่อว่าง 2 นาที แต่ยังขึ้นกับข้อจำกัดเซสชันและสิทธิ์บัญชี Codex การเปลี่ยนบุคลิกหรือเสียงใช้ผลเมื่อเริ่มเซสชันใหม่

ทดสอบแยกจากไลฟ์จริงด้วยคอมเมนต์จำลองหนึ่งข้อความ และรับคำตอบภาษาไทยพร้อมเสียงผ่าน Codex จริง โดยปิดระดับเสียงออกลำโพงเพื่อไม่แทรกไลฟ์ ยังต้องยืนยันเสียงที่ผู้ชม TikTok ได้ยินและทดสอบต่อเนื่องในไลฟ์จริง

## Euler Stream

1. กรอก TikTok username กับ Euler API key ในหน้า **การเชื่อมต่อ**
2. เลือกว่าจะใช้ key เฉพาะรอบนี้ หรือเก็บเข้ารหัสผ่านระบบปฏิบัติการ
3. กด **บันทึก** แล้ว **เชื่อมช่อง LIVE** ขณะที่ช่องเปิด LIVE
4. สถานะเชื่อมต่อสำเร็จจะแสดงหลังได้ข้อมูลห้องหรือเหตุการณ์ยืนยันจาก Euler

คีย์อยู่ใน main process และไม่ส่งไปหน้า output เมื่อไม่เลือกจำ key จะไม่บันทึก key ลงดิสก์ การปิดแอปล้าง key ในหน่วยความจำ

การปรับ payload อ้างอิง schema v3 ของ Euler โดยรับ `WebcastChatMessage`, `WebcastGiftMessage`, `WebcastLikeMessage`, `WebcastMemberMessage` และ follow จาก `WebcastSocialMessage` ข้อมูลจริงยังต้องยืนยันกับห้องที่จะใช้ ก่อนใช้ของขวัญเป็นตัวกระตุ้นระหว่างออกอากาศ

## Live2D ภายใน Dobby

1. เปิดหน้า **โมเดล Live2D** กด **นำเข้า** แล้วเลือกไฟล์ .model3.json หรือโฟลเดอร์ที่มีหลายชุด
2. เลือกโมเดลจากคลัง ภาพใน Dobby และ broadcast output ใช้โมเดลเดียวกัน
3. ปรับขนาด ตำแหน่ง และกลับด้าน การตั้งค่าบันทึกแยกต่อโมเดล
4. กด motions/expressions ที่พบในชุดไฟล์ และจับคู่กับ Action ผู้ชม
5. ตั้งพารามิเตอร์ปากตามโมเดล ค่าเริ่มต้นคือ ParamMouthOpenY

แอปอ่านไฟล์โมเดลเดิมอย่างเดียว เก็บ metadata และการตั้งค่าแยกใน userData ของ Dobby หากย้ายหรือลบไฟล์ต้นฉบับให้นำเข้าจากตำแหน่งใหม่ การแก้ artwork หรือ rig ยังทำใน Cubism Editor แล้วส่งออกชุดไฟล์ใหม่

Cubism Core เป็น runtime ที่นำเข้าผ่านปุ่ม **เพิ่ม Cubism Core** โดยเลือก live2dcubismcore.min.js จาก SDK ที่มีสิทธิ์ใช้งาน Dobby เก็บสำเนาสำหรับใช้ในเครื่องใน userData ไม่บรรจุ Core หรือโมเดลส่วนตัวในแพ็กเกจแอป

รอบพัฒนานี้ลงทะเบียนโมเดล 13 ชุดจากโฟลเดอร์ที่ผู้ใช้ระบุ และเตรียม Core ที่มีอยู่ในเครื่องแล้ว สามารถใช้ได้เมื่อเปิดแอปบนเครื่องนี้ รุ่น Core และฟีเจอร์โมเดลมีผลต่อความเข้ากันได้ จึงไม่รับรองว่าทุก .model3.json จะโหลดได้เหมือนกัน

## เสียง

เปิดหน้า **เสียงพูด** → **ตรวจ Codex และโหลดรายชื่อเสียง** → กด **ฟังตัวอย่าง** บนการ์ดเพื่อฟังเสียงนั้นได้ทันทีโดยไม่ต้องเชื่อมเอง ตัวอย่างจะหยุดเซสชันหลังจบและไม่เปลี่ยนเสียงที่บันทึกไว้ เมื่อชอบเสียงไหนให้กดการ์ดนั้น → **บันทึกและเชื่อมเสียง** แล้วกรอกข้อความและกดพูดข้อความนี้

ใช้ Codex CLI ที่ติดตั้งและล็อกอินด้วย ChatGPT (`codex login`) โดยเรียก app-server experimental ผ่าน stdio และเชื่อมเสียง WebRTC ไม่อ่านไฟล์ auth.json ไม่ดึง token ออกจาก Codex และไม่ใช้ OpenAI API key รุ่นที่ตรวจในเครื่องคือ 0.165.0 รายชื่อเสียงอ่านจาก Codex จริง จึงอาจเปลี่ยนตามรุ่น/สิทธิ์บัญชี

เปลี่ยนเสียงหรือสไตล์แล้วกดบันทึกและเชื่อมเสียงใหม่ รองรับข้อความไม่เกิน 1,000 ตัวอักษร พูดครั้งละข้อความเพื่อป้องกันเสียงซ้อน ปุ่มหยุดเสียงปิดเซสชันทันที และเซสชันแบบพูดข้อความหยุดหลังไม่มีงาน 2 นาที สไตล์เป็นคำแนะนำให้โมเดล ไม่รับรองการอ่านตรงทุกคำแบบเครื่องสังเคราะห์เสียงเฉพาะทาง

เสียงเล่นจากแอป Dobby ส่วน output มีภาพและระดับเสียงสำหรับขยับปากเท่านั้น เพิ่มเสียงแอปแยกใน LIVE Studio และตรวจเสียงซ้ำก่อนออกอากาศ การใช้งานเป็นไปตามสิทธิ์และข้อจำกัด Voice ของบัญชี ยังไม่ผ่านการทดสอบออกอากาศจริง


เลือก audio input ที่รับเสียงตัวละครเพื่อขยับปาก หากเลือกไมโครโฟน ปากจะขยับตามเสียงไมค์ การรับเสียงยังไม่ใช่การดึงเสียง Codex โดยตรง อาจต้องตั้ง virtual audio routing และผู้ใช้เป็นผู้กด “เริ่มรับเสียง” เอง

## พื้นหลังและอัตราส่วน preview

เปิดหน้า **ฉากไลฟ์** เพื่อเลือก 9:16 (1080×1920), 16:9 (1920×1080), 1:1 หรือกรอกความกว้าง/สูง 240–3840 px แล้วกดใช้ขนาดนี้

พื้นหลังมีโปร่งใส สีพื้น ไล่สี และรูป PNG/JPG/WebP ที่นำเข้าจากเครื่อง ขนาดไม่เกิน 20 MB และวิดีโอ MP4/WebM ไม่เกิน 500 MB โดยเล่นวนอัตโนมัติและปิดเสียง แนะนำ MP4 (H.264) หรือ WebM (VP8/VP9) หากไฟล์มี codec ที่เล่นไม่ได้ preview จะแจ้งให้เปลี่ยนไฟล์ รูป/วิดีโอขยายเต็มฉากและครอปกึ่งกลางโดยคงสัดส่วนเดิม ไฟล์ต้นฉบับไม่ถูกแก้ไข Dobby เก็บสำเนาสื่อสำหรับฉากใน userData

กรอบตัวละครในห้องควบคุม คลังโมเดล และหน้า output ใช้ scene เดียวกัน พื้นที่นอกกรอบเป็นพื้นที่ของหน้าจอควบคุม ลายตารางความโปร่งใสแสดงเฉพาะ preview ไม่รวมอยู่ใน output

## TikTok LIVE Studio

1. กด **ลิงก์สำหรับ LIVE Studio** ใน Dobby
2. ใน LIVE Studio เพิ่ม Link source แล้ววาง URL ที่ได้ ตั้งความกว้าง/สูงของ Link source ให้ตรงกับค่าที่แสดงในหน้าฉากไลฟ์ (เริ่มต้น 1080 × 1920)
3. หากใช้จับภาพหน้าต่าง ให้เปิด output จาก Dobby แล้วเลือกหน้าต่าง **Dobby · LIVE output** ใน LIVE Studio หน้าต่างนี้เรนเดอร์ต่อเมื่ออยู่ด้านหลังแอปอื่น แนะนำเปิดหน้าต่างค้างไว้โดยไม่ย่อระหว่างจับภาพ เพื่อให้ระบบจับภาพของ macOS ส่งเฟรมได้ต่อเนื่อง

หน้า output แสดงโมเดล Live2D ที่เลือกใน Dobby โดยตรง เปลี่ยนโมเดลได้โดยไม่เปลี่ยนลิงก์ระหว่างรอบที่เปิดแอป
4. เพิ่มเสียงตัวละครแยกจากภาพ ตรวจไม่ให้เสียงซ้ำ และทดสอบ source โหลดใหม่/สลับฉาก
5. เริ่ม LIVE จาก LIVE Studio ด้วยตนเองเมื่อพร้อม

ลิงก์ output ใช้ได้บนเครื่องเดียวกับ Dobby พอร์ตและลิงก์เปลี่ยนเมื่อเปิด Dobby ใหม่ จึงต้องคัดลอกลิงก์ใหม่ในรุ่นต้นแบบ ยังไม่รองรับส่ง output ข้ามเครื่อง
